# GTA 6 Meme on X — GTA FLU

Entry for the make.fun bounty **"Post a GTA 6 meme on X"** (`gta6-meme-x-01`).

## The meme

"GTA FLU": the make.fun ghost is sick in bed with an ice pack and a
thermometer, against a Vice City sunset with palm trees. The caption reads
"SORRY BOSS, I CAUGHT THE GTA FLU" — 212 GB download, 13 years of waiting,
midnight unlock. The `make.fun` name is shown on a pink pill at the bottom,
so the brand is visible at a glance.

## How the meme was made

The image was generated with `build_meme.py` (PIL, 1080x1080) and saved as
`meme_v3.png`. The post text is stored in `post_text.txt`.

## How to run

```sh
node main.ts
```

This reads `POST.json` and writes a copy of it to `output/POST.json`,
printing the post URL.
